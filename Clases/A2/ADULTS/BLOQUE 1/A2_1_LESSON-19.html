Build the Advice 🧩
PERSON
You
ADVICE
should
ACTION
rest
RESULT
You should rest.
TRY ANOTHER
You + should + drink some water → You should drink some water.
TO AVOID SOMETHING: You + shouldn't + stay up late → You shouldn't stay up late.
REMEMBER: SHOULD + BASE VERB · NO: should to rest · NO: should resting
