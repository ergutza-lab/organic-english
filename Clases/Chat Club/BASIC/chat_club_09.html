FIRST OBJECT CONVERSATION

1. Choose an object
2. Show it if you want
3. Say what it is
4. Add TWO details
STUDENT B
1. Listen
2. Ask TWO questions
3. React
THEN SWITCH. Target: 3 min + SWITCH + 3 min. KEEP TALKING!

MYSTERY OBJECT

I use it every day.

→ My bottle is blue.

→ It is black.

→ I use it every day.
